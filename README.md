# 如果那年 · 另一条路

> 如果那年，你选了另一条路。
> 一个人生分岔网页游戏：选一条走到底，也看一眼没选的那条后来去了哪里。

- **定位**：既有人文关怀、又能赚钱的正式项目。完整立项见 [docs/DESIGN-BOOK.md](docs/DESIGN-BOOK.md)。
- **核心机制**：选择 + 影子人生 —— 未选之路不消失，作为平行线继续运行；30/40/50 岁可瞥见它，结算时揭晓它的代价。
- **设计原则**：规则决定，故事呈现。确定性种子引擎算后果（同一种子可复现，支撑「同种子对战」），在线零 LLM 调用——所以它天然抗流量，扩容路线见 [docs/SCALING.md](docs/SCALING.md)。

## 现在就能玩（v0.15.0）
**线上**：托管定为 Cloudflare Pages（用户 2026-10-30 拍板）。仓库接入尚待用户在 Cloudflare 后台完成，站点尚未上线；接入步骤见 [docs/DEPLOY-CLOUDFLARE.md](docs/DEPLOY-CLOUDFLARE.md)，接入完成后网址为 `https://if-that-year.pages.dev`，推 `main` 自动部署。

**本地**：纯静态、免构建、免注册。用任意静态服务器打开即可：

```bash
python3 -m http.server 8000
# 浏览器打开 http://localhost:8000  （带种子: http://localhost:8000/?seed=434）
```

已实现：

- 5 条开局路线 · 8 个大分岔（选择写标记，后文事件按标记回响）· 六维数值（健康/金钱/成长/自由/关系/智慧——成长是本事、智慧是判断，吃过的亏会给智慧补偿，智慧低不触发危机）· 阈值危机 · 影子瞥视（30/40/50 岁，看与不看如实计数）。
- 开局抽牌（v0.13.0）：路线之下一层「出身」——家底 / 性子 / 时代注脚三类牌各发 3 选 1（每类第一张预选，选路不拦截；时代牌按年代分池），只改开局数值与 8 面钩子旗（对应 16 条早年回响事件），不写状态域；发牌走与主引擎隔离的独立随机流，同种子链接连手牌一起复现，牌组经净注入≈0 的双预算标定（口径与验收见开发日志 v0.13.0 条与 [docs/DESIGN-V013.md](docs/DESIGN-V013.md)）。
- 「活过的人生」（v0.13.0）：在这台设备上结算过的结局与稀有际遇会被记下来（只记种类与第一次活到的日期，存本地、不上传），开局页可回看；没活到过的只给一句侧面线索，不给名字。没有完成度、没有稀有度档位、没有集齐奖励。
- 留存记录（v0.15.0）：本地记下「有完成一局的日子」（`ify-streak-v1`）与最近一局的回看信息（`ify-lastlife-v1`：日期、年代、路线、终局年龄、事实标签、判词首行），开局页各出一行平实记录——总天数（连续 ≥2 天才提连续，断了不提）、昨天或今天那一生的判词首行。只记录，不奖励、不催促。另有每日一局：种子就是当天日期，年代与路线由日期派生、人人同日同题，开局页一键备好；旁边一行明日预告，只给明天的年代与路线。
- 人生状态走状态矩阵（v0.12.0）：配偶/子女/父母/宠物六个域是带类型的状态机——门控查当前状态，流转只能走注册表（src/registry.js）声明的边，去世类状态没有出边，数据层写不出「父亲复活」；其余叙事标记降级为注册在案的里程碑旗标。入库前必跑 `node tools/validate-state.js`（未登记引用、不可逆违规、互斥组合全报错），口径正本见 [docs/STATE-MATRIX.md](docs/STATE-MATRIX.md)。旧存档载入时自动由旧标记推导状态续玩。v0.13.0 起离异 / 丧偶后的再结伴两边已启用（各有三环专属事件，走完才流转）。
- 出生年代四档（1955 / 1965 / 1978 / 2000 年生）· 无结束年龄设置：终点由活法决定（死亡或活到 80 岁）· 同局链接带 seed + era + cards（出身牌所选）三参数（旧链接的 end 参数会被忽略；无 cards 时仍按同种子重发并对齐预选）。
- 事件池 **2092 条可抽事件**（核心 45 + 内容包 2039 + 多前置组合事件 8），另有稀有事件 28 条、特殊结局 17 个（16000 局模拟：任一特殊结局命中约 12%，传说档单条 <1%；红线：不涉政、无玄幻），全库共 2137 个 ID，另有出身牌 56 张（不可抽、只在开局发）。两局事件重合率约 6.1%（交集/平均规模口径）。结算页判词上方另有一行事实标签，只记本局真实发生过的事（路线形状、一条轨迹、晚年状态），不设档位。
- 判词按数值形状拼装：六维每维 Top/Cost 各 6 条片段（30 对 × 36 种组合 = 1080 种判词文本，模拟实测两局判词精确碰撞率 1.43%）、整局缓存同一份判词；影子人生每阶段 4 条变体文案、代价 3 条（按种子定值，结算页与分享卡同行）；8 个大分岔的 24 个选项各有专属回响文案。全程自动存档可续玩；种子可输入、可复制同局链接。
- 流水账：游玩卡下方全量流式记录本局每一年，带公历年份；贴底时平滑跟随最新，上翻回看时不被新的一年拽回去，标题旁提示「有新的一年」可点回最新。
- 自动推进三态（关 / 平年 / 全程）：平年只有无抉择年份自动走；全程连普通事件小选项也自动选并留痕，点任意处即暂停回手动；分岔/危机/稀有选项/瞥视永远必停。速度三档直接标秒数（慢约 2.8 秒 / 中约 1.6 秒 / 快约 0.8 秒，另按字数加时）。新玩家默认全程（依据见开发日志 v0.7.0 的停顿统计），偏好存在本地（ify-prefs）。
- 死亡系统：死亡风险随年龄增长、随健康降低而升高（年龄×健康模型），30 岁起另有极低的意外概率；死亡以终局卡收尾后照常结算。每年代 4000 局共 16000 局模拟：早夭 3.24%、60–79 岁死亡 6.29%、活到 80 占 90.47%、意外占全部死亡 7.68%，四项校准目标达成，模型与实测见 [docs/MORTALITY-MODEL.md](docs/MORTALITY-MODEL.md)。
- 游玩页宽屏（≥1024px）双栏：左栏当前卡、右栏流水账独立滚动；窄屏保持单栏。续玩入口为路线列表下方的次级按钮。
- 结算纵轴分岔图：判词/对照之后、年表之前——纵向时间轴自上而下（22 岁→实际终年），走过的路居中成一条松绿实线，未选的路在每个分岔口左右交替分出、灰绿虚线长一段淡去，分岔旁小字标那年选了什么；早夭局线停在终年、下方留白到 80 岁刻度位。打开时自上而下生长（点一下全显），系统减动效时静态呈现；图下紧接完整年表（人生记录只此一份）。
- 手感与无障碍（[docs/UX-MOTION.md](docs/UX-MOTION.md) 的 P0–P2 已落地）：六维条按旧值→新值真过渡（不做数字滚动）、某维跌破 30 有静态临界提示、手动选择留一拍并在回响复述所选、分岔选择有复述拍、自动推进剩余时间是一条 2px 松绿细线（暂停冻结、切档不回跳）、全程自动选最后 400ms 预高亮可夺回、按钮命中高度 44px 上下、系统减动效全站降级静态、开局防连点、续玩第一屏标注「上次玩到这里」。
- 分享台：判词卡 / 流水账卡 × 两种比例（4:5、9:16），页面内实时预览；感想可勾选印到卡上，发帖文案（感想 + 判词 + 同局链接）一键复制；系统分享（Web Share）优先，不可用时下载 PNG。

未实现：珍藏付费、影子完整推演引擎（现为查表文本）、浪潮事件组（设计已定、试点两组待用户点头，见 [docs/WAVE-EVENTS.md](docs/WAVE-EVENTS.md)）、日文版、B 端引导版、故事墙。匿名埋点已备接口（v0.13.1，`src/analytics.js`，默认关闭；v0.15.0 起 `index.html` 已预留配置注入点，收集端随 Cloudflare 接入时开启，见 [docs/ANALYTICS.md](docs/ANALYTICS.md)）。

## 仓库结构

```
index.html          入口（静态直出，部署于 Cloudflare Pages）
src/engine.js       确定性引擎（种子随机 / 状态 / 影子线 / 结算 / 分享台）
src/registry.js     状态矩阵注册表（域/状态/流转边/里程碑旗标的单一事实源）
tools/validate-state.js 状态矩阵入库门（注册表与数据双向核对）
src/events.js       核心数据（路线 / 分岔 / 年度事件 / 影子剪影 / 判词片段）
src/packs/          内容包（pack1–6、pack9–30 与 era1955/1965/1978 年代包，共 2017 条）
src/synergy.js      组合事件 8 + 稀有事件 28 + 特殊结局 17
src/style.css       纸感极简视觉（与作者主页同一套色板）
docs/DESIGN-BOOK.md 方案设计书（立项、裂变、变现、止损线、已定与待裁清单 §15）
docs/DEVLOG.md      开发日志（每次推送对应一条，含版本号规则）
docs/VISUAL-DESIGN.md 视觉与出图设计（纸感系统、分岔路图、分享卡、结算图裁定）
docs/SCALING.md     扩展与负载架构（静态优先、四级扩容）
docs/COPY-AND-AI.md 文字原则（自然人语感）与 AI 使用边界（对局与结算不用 AI，AI 仅离线辅助）
docs/DEPLOY-CLOUDFLARE.md Cloudflare Pages 接入步骤（后台点选清单与排障）
docs/PM-GROWTH.md   增长方案（首页克制、分享闭环、留存与指标，含状态更新）

docs/REVIEW-COMPLETENESS-V013.md 六角色完成度评审归档（v0.13.0 时点，结论原文）
content-drafts/     事件库研究稿与史实出处清单（SOURCES.md）
_headers            Cloudflare Pages 缓存与响应头规则
```

## 开发纪律

一个工作副本、一仓一主线；内容（事件文案）上线前必须过设计书 §6.3 审核四问；数字进文案必须有出处，查不到就降级为定性描述。每次改进推送 GitHub 并在 docs/DEVLOG.md 记一条。
