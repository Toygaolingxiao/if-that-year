# 如果那年 · 另一条路

> 如果那年，你选了另一条路。
> 一个人生分岔网页游戏：选一条走到底，也看一眼没选的那条后来去了哪里。

- **定位**：既有人文关怀、又能赚钱的正式项目。完整立项见 [docs/DESIGN-BOOK.md](docs/DESIGN-BOOK.md)。
- **核心机制**：选择 + 影子人生 —— 未选之路不消失，作为平行线继续运行；30/40/50 岁可瞥见它，结算时揭晓它的代价。
- **设计原则**：规则决定，故事呈现。确定性种子引擎算后果（同一种子可复现，支撑「同种子对战」），在线零 LLM 调用——所以它天然抗流量，扩容路线见 [docs/SCALING.md](docs/SCALING.md)。

## 现在就能玩（v0.6.0）

**线上**：托管定为 Cloudflare Pages（用户 2026-10-30 拍板）。仓库接入尚待用户在 Cloudflare 后台完成，站点尚未上线；接入步骤见 [docs/DEPLOY-CLOUDFLARE.md](docs/DEPLOY-CLOUDFLARE.md)，接入完成后网址为 `https://if-that-year.pages.dev`，推 `main` 自动部署。

**本地**：纯静态、免构建、免注册。用任意静态服务器打开即可：

```bash
python3 -m http.server 8000
# 浏览器打开 http://localhost:8000  （带种子: http://localhost:8000/?seed=434）
```

已实现：

- 5 条开局路线 · 8 个大分岔（选择写标记，后文事件按标记回响）· 五维数值（健康/金钱/成长/自由/关系）· 阈值危机 · 影子瞥视（30/40/50 岁，看与不看如实计数）。
- 出生年代四档（1955 / 1965 / 1978 / 2000 年生）· 结束年龄可选（60 / 65 / 70 / 75 / 80 岁，默认 65）· 同局链接带 seed + era + end 三参数。
- 事件池 **1156 条可抽事件**（核心 43 + 内容包 1105 + 多前置组合事件 8），另有稀有事件 16 条、特殊结局 12 个（4000 局模拟：任一特殊结局命中约 10%，传说档单条 ≤0.75%；红线：不涉政、无玄幻），全库共 1184 个 ID。两局事件重合率约 7.6%。
- 判词按数值形状拼装（片段可数组变体、整局缓存同一份判词）；全程自动存档可续玩；种子可输入、可复制同局链接。
- 流水账：游玩卡下方全量流式记录本局每一年，带公历年份。
- 自动推进：无抉择的年份可自动往前走，速度三档（慢/中/快），凡抉择必停；默认关，偏好存在本地（ify-prefs）。
- 分享台：判词卡 / 流水账卡 × 两种比例（4:5、9:16），页面内实时预览；感想可勾选印到卡上，发帖文案（感想 + 判词 + 同局链接）一键复制；系统分享（Web Share）优先，不可用时下载 PNG。

未实现：珍藏付费、影子完整推演引擎（现为查表文本）、判词池加厚与写手第三轮（计划见 [docs/PM-CONTENT.md](docs/PM-CONTENT.md)）、浪潮事件组（设计已定、试点两组待落地，见 [docs/WAVE-EVENTS.md](docs/WAVE-EVENTS.md)）、结算纵轴分岔图（已裁定待落地，见 [docs/VISUAL-DESIGN.md](docs/VISUAL-DESIGN.md) 第四节）、日文版、B 端引导版、故事墙、匿名埋点。

## 仓库结构

```
index.html          入口（静态直出，部署于 Cloudflare Pages）

src/events.js       核心数据（路线 / 分岔 / 年度事件 / 影子剪影 / 判词片段）
src/packs/          内容包（pack1–6、pack9–14 与 era1955/1965/1978 年代包，共 1105 条）
src/synergy.js      组合事件 8 + 稀有事件 16 + 特殊结局 12
src/style.css       纸感极简视觉（与作者主页同一套色板）
docs/DESIGN-BOOK.md 方案设计书（立项、裂变、变现、止损线、已定与待裁清单 §15）
docs/DEVLOG.md      开发日志（每次推送对应一条，含版本号规则）
docs/VISUAL-DESIGN.md 视觉与出图设计（纸感系统、分岔路图、分享卡、结算图裁定）

docs/DEPLOY-CLOUDFLARE.md Cloudflare Pages 接入步骤（后台点选清单与排障）
docs/PM-GROWTH.md   增长方案（首页克制、分享闭环、留存与指标，含状态更新）
docs/PM-CONTENT.md  内容方案（判词池、影子线、年代供给实测与下一轮配额，含状态更新）
docs/WAVE-EVENTS.md 浪潮事件组设计（大事件必经、个人路线分流）

content-drafts/     事件库研究稿与史实出处清单（SOURCES.md）
_headers            Cloudflare Pages 缓存与响应头规则
```

## 开发纪律

一个工作副本、一仓一主线；内容（事件文案）上线前必须过设计书 §6.3 审核四问；数字进文案必须有出处，查不到就降级为定性描述。每次改进推送 GitHub 并在 docs/DEVLOG.md 记一条。
