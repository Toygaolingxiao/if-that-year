# v0.11.0 全轮共用简报（协调者制定，所有写手/修复员逐字执行）

## 〇、全局红线与文案法
docs/COPY-AND-AI.md 全文为准：具体场景、账本式数字、过朗读测试；禁词零命中（后来你才知道/才明白/原来这就是/不禁/油然而生/岁月/时光荏苒/人生就是/江湖）；伴侣只称「对方/另一半」，玩家孩子不写性别，他人孩子非必要不写；不涉政不评价、不玄幻、写事不写惨、稀有≠高贵。维度键只许六个：health/money/growth/freedom/relation/wisdom。新事件不写负智慧；智慧单次 +2..+5；单项效果 −10..+10、单事件合计绝对值 ≤14。route 只许 corp/home/abroad/study/gap；era 只许 c1955/c1965/c1978/c2000；when 只许对象形 {stat, lt|gt}。立旗：无选项事件用顶层 set，有选项事件用选项级 set（顶层 set 本轮起引擎在呈现时对所有事件生效——死亡类旗靠它保证必立）。require/forbid/all/any 只许引用真实存在的旗标（清单见 ~/workspace/sim-v0110/lists/flags.txt，需要新旗先报协调者批准）。

## 一、新口径：「人生不如意十有八九」（本轮新写内容全适用，优先级等同红线）
效果签名四类定义（按事件全部结局计：本体 effects 与每个选项 effects 各算一个结局）：
- **纯正**：每个结局都无负值、且净和 >0。
- **持平**：每个结局净和 =0 且正值合计 ≤1（允许 effects 为空）。
- **净负**：每个结局净和 <0。
- **权衡**：其余（有得有失、或不同选项走向不同）。
配比纪律（本轮全部新增内容）：**纯正 ≤1/3**；其余为权衡/持平/净负。稀有事件尤其执行「稀有≠幸运」：新增稀有至少一半苦味/负面/两难向。每条新线至少 2 条持平收尾事件（事落定、没变好也没变坏，允许零效果）。写完自查签名并在回报里给出本包四类计数；超标由协调者退回改效果方向（文案事实不动）。

## 二、字段约定（本轮新增/新规）
- `minYear`（数字，公历年）：事件最早可发生的公历年。引擎按 出生年+当前年龄 过滤。只给「换个公历年就不成立」的现代事物事件打：取值 = 该事物进入日常生活的年份（清单里已给候选年份，逐条核对文本后采用或修正）。不要给留白/通用生活事件乱打。
- `w`（数字，权重倍数）：只给 35–55 岁段苦味/沉重事件打 `w:2`（不可逆的失去：亲人去世、重病、失业/倒闭、破财、关系破裂、被骗惨了）。其余不打。
- 生死旗（本轮新建，全库统一）：`dad_dead`（父）、`mom_dead`（母）、`spouse_dead`（老伴）、`cat_gone`（猫）、`dog_gone`（狗）、`gp_dead`（祖辈）。规则：
  - 叙述主角的该亲属/宠物去世的事件：必须立对应旗（无选项→顶层 set；有选项→顶层 set 同样有效，本轮引擎呈现即立）。
  - 同一亲属的多个去世变体（如猫的两种死法）：每条都同时写 set 与 forbid 同一旗——先抽到的立旗，后到的被 forbid 挡住，天然互斥。
  - 预设该亲属/宠物「活着在场」的事件（现时叙述：陪诊、打电话、拌嘴、遛狗、喂猫等）：加 forbid 对应旗。回忆/过去时提及不加。
  - 入库校验门：去世事件无旗不许交付。
- `divorced`（本轮新建）：离异线入口事件立旗，后续离异线事件 require 它。
- 状态门控补课口径：事件文本以**第一人称预设**配偶/子女存在、且没有他们场景就不成立的 → 补 require（配偶→partner，子女→has_kid，孙辈→has_kid）。只是提及他人伴侣/孩子、场景笔触、回忆、相亲/相识/领证/出生等「形成过程」事件**不补**。补 partner 的同时给该事件加 forbid:["divorced","spouse_dead"]（已有 forbid 的合并）。注：partner 旗只有 31 岁分岔第一项立，slow_love 的人没有此旗——形成过程事件正是留给他们的，不许误关。

## 三、数据文件纪律
- pack 文件是一行一事件的 JSON 对象（era 包同），改哪条只动哪行；events.js 是手写 JS，保持原格式风格。
- 改完每个文件必须 `node --check` 通过。
- 回报格式：逐文件、逐修复类型给计数 + 点名清单（id 列表）；判断为「不适用」的候选也要列 id+一句理由（抽样列即可，但总数要报）。
- 不许动分配给你之外的文件；不许动 src/engine.js、src/style.css、index.html（归协调者）。
