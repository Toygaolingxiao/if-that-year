# 独立评审与重设计 v2（2026-10-30）

> 用户要求：换完全独立的思考模式，以最严格最苛刻的玩家视角评测现有建构，再以资深产品经理与游戏开发大师视角重新设计并改进。
> 本文 = 问题清单（实测数据支撑）+ 重设计纲要 + v0.2 已落地/未落地对照表。评审由独立评审者逐行读代码完成，其量化结论经主线 500 局模拟独立复现。

## 一、最难听的结论（评审原话）

「这不是一个游戏。这是一个套着游戏外壳的、只有 9 次真实点击决策的图文幻灯片，而它赖以立项的三个卖点——选择有后果、影子人生、同种子对战——在代码层面全部是假的。文档写了约 600 行的宏大设计书，代码兑现的不到一成。**这个项目不缺想法，缺的是有人认真玩上第二局，并诚实承认这不好玩。上面所有 P0 都有一个共同特征：不需要任何专业能力就能发现，只需要玩第二局。**」

## 三、问题清单（分级）

**P0（不修产品不成立）**
- P0-1 选择与后续事件零因果；P0-2 内容量差一个数量级；P0-3 影子是查表台词，无推演无代价；P0-4 无存档续玩；P0-5 裂变三断（无入口、回流随机局、出图不可靠）。

**P1（上线即口碑事故）**
- P1-1 判词被通胀垄断大面积撞句；P1-2 「不看影子」欺骗玩家；P1-3 路线错位穿帮；P1-4 分岔状态不一致（选独身后冒出「你们」）；P1-5 留言承诺/转义；P1-6 无分享基础设施；P1-7 文档虚假「已落地」。

**P2**
- 病句与性别预设、输入框 14px 触发 iOS 缩放、年表锁在 300px 小窗、非 Mac 衬线回落、抽事件 O(n²) 与递归跳年。

## 四、重设计 v2 纲要（评审纲要 + 主线取舍）

1. **核心循环改版**：每年都是一道小题（年度事件带小选择，选完当场给叙事回响 echo），分岔是大题。循环 = 预判 → 选择 → 当年回响 → 隔几年后的「回响事件」回来结账。
2. **回响系统是地基**：每个分岔选择写状态标记（flags）；事件支持 require/forbid/route 条件；回响事件加权优先抽中。没有回响，就没有人生，只有问卷。
3. **影子 2.0**：瞥视先给标题（teaser），点开才看全文，不看次数是真数据并进入结算叙事；每阶段 2 个变体；结局揭晓独立的「代价」句，且优先展示玩家没看过的那条近况。完整推演版影子引擎（双线同规则模拟）列为下一阶段，先把「查表」升级为「与路线/阶段/是否看过严格一致」。
4. **数值要有牙齿**：全生命周期配平（终值期望 45–75）；阈值危机事件（健康<30 / 金钱<20 / 关系<25 各一条两难事件链的入口）；判词改用数值**形状**（最高维写你靠什么活、最低维写你付的价），撞句率目标 <5% 完全相同。
5. **内容生产改法**：先砍规模保密度——事件结构带条件与标记，写作单元从孤立事件改事件链；数量目标分阶段（本轮 43 条带条件事件 + 12 条回响 + 10 条路线专属）；扩容时两道机器硬检：路线错位扫描、状态一致性扫描，再过朗读测试。
6. **底线工程**：自动存档+断点续玩先于一切新功能；种子输入框 + 可复制同局链接 + OG 标签；一切计数型文案必须有真实数据支撑，做不到就删文案；文档纪律——每篇文档的「已实现」表述必须能与代码逐项核对。
