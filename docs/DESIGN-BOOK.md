# 《另一条路》（暂名）方案设计书 v0.1

> 一句话定位：一个让你亲手选、亲眼看着另一条路展开的网页人生分岔游戏。
> 不是投胎抽卡，不是成功学模拟器。核心问题只有一个：**「如果那年我选了另一条，会怎么样？」**
>
> 项目定位（用户 2026-10-30 定）：既有人文关怀、又能赚钱的正式项目。
> 设计原则（沿用用户一贯主张）：**规则决定，AI 解释** —— 确定性引擎算后果，文案/AI 只负责把后果讲成故事。数字可核查，不编造，不贩卖焦虑。
>
> 本书口径：所有收入/转化数字均为情景测算，不是承诺；所有引用的行业数据均注明来源；不确定处明确标「待验证」。
>
> 2026-10-30 补充（用户拍板）：文字表达以自然人语感为准，结算总结用模板+规则实现、全程不调用 AI Agent，AI 仅作离线内容辅助——细则见 `docs/COPY-AND-AI.md`，与本书冲突处以该文为准。

## 0. 结论先行（客观版）

1. **题材不是伪需求。** 「低门槛文字人生 + 强分享结果」这个组合，过去几年在中文互联网与全球市场被反复验证：有产品在零买量下靠口传做到过亿级访问量，也有同类长线产品常年保持可观的付费收入。需求真实存在，本项目要争的是同一需求里还没被占住的那个位置（见第 3 条）。
2. **但爆款不可设计、只能提高概率。** 这类产品反复成立的共同点不是画质或系统深度，而是：即开即玩、一局短、结果独一无二且可晒、情绪后劲大。本书所有设计都围绕「提高这四件事的概率」，不承诺爆。
3. **差异化不在题材，在机制。** 入口已经被占了两个：随机投胎、抽卡重开。我们占第三个位置：**选择 + 影子人生**——未选之路不消失，作为平行线继续运行，玩家在 30/40/50 岁可以瞥见它。这既是原创钩子，也是全项目最强的分享点和付费点。
4. **C 端养名气，B 端养收入，是算过账的结论（见 §10）。** C 端珍藏付费在 10 万玩家量级只有几十万日元量级；广告更低一个量级。真正的收入杠杆是教育/企业授权和定制服务。路线必须是「C 端裂变获客 → 数据与口碑 → B 端变现」，顺序反了做不起来。
5. **最大风险不是技术，是内容和口径。** 事件库的文案质量、价值观分寸、敏感话题处理，决定它是被转发还是被骂。技术是最简单的部分（纯前端即可起步）。
6. **止损线先定。** 沿用副业 Phase 0 的纪律：先用最小版本验证三个数——完局率、分享率、首笔付费。数不过线就停或转 B 端工具，不无限加内容。具体门槛见 §12。

## 1. 定位、命名与市场选择

### 1.1 一句话与三句话
- 一句话（对外）：如果那年，你选了另一条路。
- 三句话（落地页）：22 岁那年站在路口的你，一边是你选的，一边是你没选的。这局游戏里，两条都让你活完。最后你会拿到一张卡，上面写着你最关键的那次选择，和另一条路上的你最后去了哪里。

### 1.2 命名候选（待用户一次拍板）
| 候选 | 优点 | 风险 |
|---|---|---|
| 《如果那年》 | 情绪最准，自带故事感，搜索唯一性尚可 | 略文艺，需要副标题补玩法 |
| 《另一条路》 | 直白、好记、域名/话题友好 | 重名较多 |
| 《分岔口》 | 机制感强 | 情绪弱 |
| 《第二人生》 | 认知成本最低 | 太泛、商标与同名产品风险高，不建议做主名 |
建议：主名《如果那年》，副标题「另一条路 · 人生分岔模拟」。英文工作名 The Road Not Taken（注意弗罗斯特诗名，致敬可用、注册商标需另查，待验证）。

### 1.3 首发市场：先中文，后日文，不先做英文
- **中文先行**：作者母语写作质量最高（本项目成败在文案）；小红书/B站/微博/Threads 华语圈是此类情绪产品被验证过的裂变场，这类产品最出圈的一次传播就发生在中文互联网。
- **日文第二**：作者在日、有 Stripe 等收款通道和在地生活成本数据（房租、育儿、正社员/派遣等），变现测试和 B 端（日本学校生涯教育、企业员工关怀）更可落地；且日文版可反哺「在日华人」这个高共鸣小圈层做种子。
- **英文最后**：当地已有成熟的同类长线产品占位、文化事件库要重写、获客成本最高。等中文版数据成立再考虑。
- 待验证：微信生态对外链 H5 的限制、国内收款与内容合规。若首发重心在大陆平台，需单独评估「绕开微信内传播、用小红书/B站/抖音落地页导流」的路径，不要默认朋友圈可裂变。

## 2. 设计取舍：做什么、不做什么

立项时定下的取舍，理由只写本身。

| 做 | 理由 |
|---|---|
| 主动选择开局（5 条路线自选） | 题眼是「如果那年我选了另一条」：出身由玩家自己选，影子线才有对照意义 |
| 结算卡与影子对比卡 | 玩家产出的结果物本身就是传播物；在本项目的优先级里排在玩法系统前面，不是美术收尾工作 |
| 里程碑反思暂停点 | 在几个年龄停下来让玩家写一句话，这句话进结算——卡因此是「我的表达」，不只是游戏结果（§4 第 3 条） |
| 珍藏付费模式、免费完整玩 | 收费只卖纪念、定制、内容包、机构工具，永不卖改命与好结局（§10） |
| 事件按年龄/条件触发，池子做厚 | 选择要有回响，第二局不能明显重复（现状实测见 docs/PM-CONTENT.md） |
| 开局轻仪式感、碎片时间可玩 | 一局 6–25 分钟两档（§3），通勤与睡前都能完局 |
| 长线内容更新（主题包） | 一局制产品靠新内容维持回访与再报道（§6.4） |
| 真实数据背书（关键后果处） | 可信度是 B 端敢采购的前提；数字逐条查证，查不到就降级为定性描述（§5 L2） |
| 分享卡不剧透全过程 | 只给结果形状（判词、关键分岔、影子一行、六维小图）；过程留给点进来的人自己活（§8.1） |
| 同种子共同题目 | 同样的运气、不同的选择——可比性产生讨论，讨论产生传播（§8 Loop C） |

| 不做 | 理由 |
|---|---|
| 随机出身 / 抽卡开局 | 立项时以「与主动选择冲突」否决；**已被 v0.13 裁定修订，边界见 docs/DESIGN-V013.md §A2.4**（运气发牌、玩家选牌、路线仍是脊柱） |
| 全球规模数据库 | 一个人维护不起；真实数据只在关键后果处挂 |
| 全靠 LLM 现场生成 | 成本、语气漂移与前后矛盾风险；对局与结算零在线调用（docs/COPY-AND-AI.md） |
| 纯搞笑梗路线、自嘲式标题 | 与人文定位冲突，且梗会过时 |
| 看广告解锁式变现 | 破坏沉浸与口碑；广告不进 MVP（§10.6） |
| App 形态起步 | 先网页验证，链接才是裂变载体；上架是验证成立后的第二步 |
| 每日一题节奏 | 人生局太长，不适合日更主玩法；可做每日一分岔轻版作引流 |

## 3. 用户与场景（横向人群）

| 人群 | 典型时刻 | 他们要什么 | 对应设计 | 主要渠道 |
|---|---|---|---|---|
| 18–24 学生/应届 | 毕业、考研、考公、留学、第一份工作前夜 | 「帮我预演一下，别让我选错」的安全彩排 | 毕业分岔主线、教育版反思单 | B站、小红书、学校社团 |
| 25–34 职场人（主力） | 深夜、通勤、跳槽/裸辞/回老家念头冒头时 | 情绪出口 + 「原来不只是我这样」的确认 | 职场主线、影子人生、匿名故事墙 | 小红书、X/Threads、即刻 |
| 35–45 中年 | 育儿、房贷、父母生病、行业下行 | 被理解，而不是被教做人；平凡结局的尊严 | 家庭/照护事件线、结局不分贵贱 | 微信群（待验证）、知乎、播客联名 |
| 情侣/朋友/家人 | 聚会、过年、同学群 | 一起玩、互相晒、聊各自的选择 | 同种子对战、双人局、亲子局（家长与孩子同玩一局） | 线下口传、群聊分享卡 |
| 教师/咨询师/企业 HR | 生涯课、团建、员工关怀活动 | 一个能引发讨论、带讨论提纲的工具 | B 端引导版（讨论题+教师手册） | 机构采购、教育展会、口碑转介 |

场景约束（决定形态）：以手机竖屏、碎片时间、单手点击为主；一局目标时长分两档——**轻局 6–8 分钟**（通勤可完局，负责裂变）和**完整局 18–25 分钟**（负责口碑与付费）。先做轻局，完整局是扩展，不是 MVP 前提。

## 4. 情绪引擎：为什么大家会喜欢（心理机制逐条落到设计）

1. **反事实思考（counterfactual thinking）**：人天然会想「要是当时……」。游戏把这种日常反刍变成可操作的实验——满足感来自「终于能看一眼」，不是来自赢。→ 设计：每个大分岔必须生成影子线，哪怕玩家不点开，存在本身就是钩子。
2. **可能的自我（possible selves）**：人对「可能成为的我」有强烈好奇与情感投入。→ 设计：影子人生给的是片段和剪影（职业、城市、家庭状态、一句近况），不给全量数据，留白才像真实的人生想象——现实中我们对没走的路也总是美化且信息不全的，机制与心理同构。
3. **叙事认同**：玩家不是在玩角色，是在借角色讲自己。→ 设计：里程碑反思节点让玩家写一句话给现实的自己，这句话进结算卡——卡因此从「游戏结果」变成「我的表达」，分享动机从炫耀变成表态。测试类 H5 的传播研究同样指出，分享由认知、情感、社交（标榜/谈资/认同）多重动机驱动，结果卡必须同时喂这三种动机。
4. **安全的彩排与宣泄**：辞职、回老家、丁克、再出发——现实代价高的选择在游戏里零成本试错。→ 设计：不嘲讽任何选择，不设「正确路线」；随机事件让任何路线都有好坏年份，避免变成说教。
5. **共同题目感**：「大家在做同一道题」天然带来讨论与比较。→ 设计：同种子分岔（§8 Loop C）让朋友用同一起点、同批随机事件，只比选择——可比性产生讨论，讨论产生传播。
6. **完成与纪念**：一局是一个完整人生，天然有「留住它」的冲动。→ 设计：珍藏产品卖的是纪念，不是数值（§10）。

**语气定调**：温暖但不煽情，诚实但不残酷，偶有幽默但不玩梗至上。取舍很明确：克制优先于梗密度——不回避沉重，但给日常温情。语气是本项目最重要的一条「功能需求」，写进事件库审核标准（§6.3）。

## 5. 核心玩法系统（从简单到复杂，分四级）

### L0 最简版（MVP，验证情绪）
- 起点：22 岁毕业分岔（5 条初始路：大城市大厂 / 留学读研 / 回家乡体制内 / 创业或自由职业 / 先间隔年再定）。
- 推进：按年推进，每年 1 张事件卡（点击继续），大分岔点 12–15 个（工作变动、结婚与否、买房、父母健康、行业波动、要不要孩子、中年转行等），每点 2–3 个选项。（现状：已落地 8 个大分岔，位于 25/28/31/33/38/44/52/58 岁，每点 3 个选项。）
- 数值：6 维——健康、金钱、成长、自由、关系、智慧（智慧为 v0.9.0 新增）。用条形而非排行榜呈现；数值只影响事件概率与结局文案，不做胜负判定。成长与智慧的划界：成长 = 本事（技能、证书、职业资本，靠学习与练习得，前半生涨为主）；智慧 = 判断（阅历与吃亏换来的判断力，全程可涨、后半生尤其）——部分坏事件在扣其他维度的同时给智慧补偿，智慧不进危机系统（低智慧不触发危机）。
- 结局：65 岁退休结算（轻局先到 65 岁，不做到死亡，降低沉重感与内容量；完整局再延长）。（现状：结束年龄可选 60/65/70/75/80、默认 65，见 §15 已定。）
- 产出：结算卡 1 张（见 §8.1）。

### L1 影子人生（差异化核心，MVP 后第一个加）
- 每个大分岔，未选分支生成影子状态，后台用同一规则简化推演（只保留职业/城市/家庭/一句话近况，不算全量数值，控制复杂度）。
- 在 30 / 40 / 50 岁设「瞥一眼」节点：玩家可选择看或不看（不看也是一个会被讨论的设计——结算卡会标注「你有 2 次没敢看」）。
- 影子信息刻意不完整且略带美化滤镜，结局时揭晓影子线的真实代价（例如那边收入更高，但关系维更低、有一段没人知道的低谷）——完成「另一条路也不是天堂」的主题闭环。

### L2 真实数据层（可信度与媒体点）
- 关键后果挂真实数据并标注来源：各城市/路径的收入中位数区间、房租与购房门槛、育儿时间与费用量级、不同选择的统计分布（如「现实中，毕业回县城的同学里 X% 三年内又离开」——具体数字必须逐条查证后才可上线，查不到就不写数字，只写定性描述）。
- 页面设「数据与虚构说明」：哪些是统计、哪些是叙事虚构，一次说清。这是与跟风山寨拉开差距、也是 B 端敢采购的前提。

### L3 个性化与 UGC（复杂版）
- 自定义起点：玩家输入自己的真实分岔（年龄、选项 A/B），系统用事件库模板拼装专属局（AI 只做文案适配，规则仍走确定性引擎，生成后过事实/敏感词检查）。
- 主题人生包：县城青年、女性重启、大龄转行、照护父母、海外漂泊等专题包（可与播客/出版社/公益机构联名）。
- 故事墙：玩家匿名投稿自己真实人生的分岔故事，经审核与授权后发布；可点烛/留言。UGC 是长尾流量与媒体素材池，但审核成本真实存在，放在数据成立之后。

### L4 B 端引导版
- 教师/咨询师模式：局后自动生成讨论提纲（你的关键分岔是什么、影子线改变了你的看法吗、现实里你正在哪个路口）、课堂活动单、教师手册。
- 企业版：用于员工职业发展/心理关怀活动的轻量版，去除敏感事件，提供组织者后台（场次码、匿名聚合报告——只给聚合，不给个人数据）。

## 6. 内容系统（本项目的真正护城河与最大成本）

### 6.1 事件库结构
每个事件是一条结构化记录：`id / 触发年龄区间 / 前置条件（路线、数值阈值、已发生事件）/ 权重 / 选项×2–3 / 每选项的数值变化与后续标记 / 文案（标题+两三句叙事）/ 影子线对应处理 / 数据来源（可选）/ 敏感等级`。

### 6.2 数量门槛（经验值，待内测校准）
- L0 轻局可玩下限：通用事件 ≥120 条 + 每条初始路线专属事件 ≥30 条 + 大分岔 12–15 个。（现状：大分岔为 8 个；事件池已远超下限，见下一条。）低于此数，第二局就开始重复，分享率会掉。
- 完整局目标：事件总量 600–900 条量级（我们单条更重，数量可少、质量要高）。现状已超此目标：可抽事件池 1156 条（实测口径见 docs/PM-CONTENT.md）；下一轮配额以补薄格子为主，不再单纯追总量。
- 生产方式：人工定框架与语气样张 → AI 按模板扩写 → 人工逐条审（价值观、事实、重复度）。**不审不上线**是红线，AI 直出内容是本项目最大的口碑风险点。

### 6.3 文案公式与审核标准
- 公式：一句具体场景（有时间、地点、小动作）+ 一个真实代价或甜头 + 不下结论。例：「你在县城的冬夜里陪父亲复查，报告没事。同一周，大城市的老同学升了总监。」——只陈述，不评判。
- 审核四问：是否把某种活法写成了笑话或惩罚？数字有出处吗？沉重事件旁边有没有日常温情平衡？未成年人/患者/特定群体读者会不会被刺伤？

### 6.4 更新节奏
按季节与人生节点更新小包（毕业季包、过年回家包、高考志愿包），制造可反复回访与媒体再报道的理由；更新公告本身就是内容（开发者日志适合独立产品冷启动：公开记录制作过程，本身就能带来第一批读者）。

## 7. 人文关怀系统（不是章节点缀，是验收标准）

1. **结局尊严矩阵**：结局称号与判词按「健康、关系、自由、成长、金钱」多维组合生成，任何一维突出都可得到体面判词；禁止出现以财富/职位为唯一尺度的「人生赢家/失败者」话术。平凡陪伴型结局的判词质量要与高成就型同等认真写。
2. **敏感话题协议**：疾病、亲人离世、失业、抑郁、自伤等——①出现前有内容提示与跳过选项（教育版默认柔和模式）；②自伤相关内容只按「求助与陪伴」方向写，附当地求助资源（日/中分别核实后上线，号码必须查证、定期复核）；③不把苦难做成随机笑点，不 gamify 他人的不幸。
3. **不制造现实焦虑**：局后文案落点是「理解自己的选择」，不是「你选错了」。禁止「90% 的人后悔没选 B」式恐吓文案（除非有真实统计且语境完整）。
4. **包容性**：性别、婚育（结/不结、要/不要孩子）、性取向、残障、单亲、再婚等路径都可玩且完整；在事件写作阶段就按清单自查，不靠上线后补。
5. **隐私与数据最小化**：MVP 免注册、存档只在本地（localStorage）；反思文字默认仅本地保存，投稿故事墙需单独明确同意；B 端只输出聚合数据。隐私做法本身写进落地页，是信任卖点。
6. **效果宣称边界**：可以说「引发反思、帮助讨论」，**不能**宣称治疗、改善心理健康或提高决策正确率等未经验证的效果。教育游戏对拓宽职业视野有研究支持（如瑞士 like2be 的 809 人准实验显示可拓宽职业选择视野，但对深度自我反思的刺激有限）——B 端材料引用研究时按原结论强度说话，不夸大。

## 8. 裂变设计（核心章节：把分享做进产品，而不是上线后求转发）

### 8.1 裂变 Loop A：结算卡（主引擎）
一局结束生成竖版分享卡（适配小红书/微信/Threads 尺寸），必须包含 5 个元素，缺一不可：
1. 一句判词（可截图当标题，如「你选了自由，自由也选了你」）；
2. 关键分岔 1 个（「28 岁，你没回老家」）；
3. 影子人生一行（「另一条路上的你：县城中学老师，两个孩子，周末钓鱼」）——这是别人没有的元素，是好奇心入口；
4. 六维小图（不剧透全过程，只给结果形状）；
5. 二维码/短链 + 一句钩子（「你敢看你的另一条路吗？」）。
卡面不放分数排名，不放「击败了 X% 玩家」。

### 8.2 裂变 Loop B：影子挑战（定向邀请）
结算后可生成专属链接发给某个具体的人：「我这局没敢回老家。你来试试选回去会怎样？」——定向挑战的转化远高于广播分享，因为它是一对一的社交动作。被挑战者开局即带挑战上下文，结束后自动生成两人对比卡（第二张卡 = 第二轮传播）。

### 8.3 裂变 Loop C：同种子对战（可比性引擎）
每个种子 = 一套固定起点+随机事件序列。玩家可把本局种子码发给朋友：同样的运气、不同的选择。产出「同命不同路」对比卡。同种子是本项目「共同题目感」的核心设计（§4 第 5 条），也是同学群/同事群场景的天然玩法。每周官方推一个「本周分岔种子」（如毕业季种子、过年种子），制造公共话题与媒体抓手。

### 8.4 裂变 Loop D：双人/亲子局（线下场景）
同一台设备两人轮流为同一角色做选择（或各选一条线并行），适合情侣、朋友、家长与孩子。价值不在数据，在场景：过年回家、同学聚会时被掏出来玩一次，等于一次线下路演。

### 8.5 裂变 Loop E：内容型传播（创作者与媒体）
- 开发者日志：从第一天公开记录制作过程、事件库写作、数据查证、内测故事——这是独立产品被反复验证的冷启动路径。
- 故事征集：上线后征集玩家真实分岔故事（授权后改编进事件库并署名鸣谢）——玩家变共创者，共创者自带传播。
- 媒体角度预置（写进新闻稿素材包）：「AI 时代的人生模拟」「用真实数据算选择代价」「一个让你看另一条路的游戏」——给记者现成的三个标题方向。
- 短视频脚本预置：官方先拍 3 条样板（完整一局加速版、影子揭晓瞬间、玩家反思金句），给二创一个模仿模板。

### 8.6 裂变数学（把「爆」拆成可测的乘法）
广播式分享的新增/玩家 = 分享率 × 每份分享的平均曝光 × 点击转化率。情景表（每玩家带来的新玩家数）：

| 分享率＼曝光×转化 | 20 曝光 ×1% | 50 曝光 ×2% | 150 曝光 ×2% | 150 曝光 ×5% |
|---|---|---|---|---|
| 10% | 0.02 | 0.10 | 0.30 | 0.75 |
| 20% | 0.04 | 0.20 | 0.60 | 1.50 |
| 35% | 0.07 | 0.35 | 1.05 | 2.62 |

读法：**单靠玩家自发分享，绝大多数情景下系数 <1，不会自爆。** 爆发需要外力把「曝光」那一格顶上去——平台推荐（小红书/B站信息流）、KOL/媒体单次大曝光、或官方种子话题进热点。所以推广预算与创作者 seeding 不是可选项，是裂变公式里缺的那一项。定向挑战 Loop B 用邀请制 K 因子单独算：K = 人均发出邀请数 × 邀请转化率，目标先做到 0.2–0.3（即每 5 个玩家带来 1 个新玩家），与广播 Loop 叠加后才接近自增长。

### 8.7 反裂变风险
- 分享卡太像「测试结果图」会被平台限流或被用户当低质 H5 划过——卡面设计要像海报，不像广告。
- 诱导分享（分享解锁结局等）伤害人文定位且可能违规——**禁止**用分享做任何解锁门槛。
- 微信内传播路径、诱导分享规则等平台政策上线前逐条核实（待验证），不把裂变押在单一平台。

## 10. 变现设计（从简单到复杂，五级）

**总原则**：免费玩完整一局，永远免费。收费只卖四样东西——纪念、定制、内容包、机构工具。永不卖：改命、好结局、数值、解锁人生路线、去广告式打扰（MVP 不放广告，见 10.6）。

### L1 珍藏版（最先上线，验证第一笔钱）
- 内容：高清结算海报（可打印）、《我的一生》PDF 小书（全程年表+反思文字排版）、影子人生完整报告（另一条路的全程年表与代价揭晓）。
- 定价：单局珍藏 ¥680；三件套 ¥980（日元区）；中文区用等值本地定价（待定；市面同类珍藏付费的低价锚约在 NT$90 一带，仅作量级参考——我们的内容更重，可略高，但首测建议压在「一杯咖啡」心理价位内 A/B 测 ¥480/¥680 两档）。
- 支付：Stripe（自有站无应用商店 30% 抽成是网页形态的真实优势；具体费率上线前以 Stripe 日本现行公示为准，待验证）。

### L2 完整版通行证（内容量起来后）
- 一次买断（建议 ¥1,980–2,480）：全部主题人生包、完整局（活到终点）、多存档、双人局高级对比报告。**不做订阅**——一局制产品没有订阅心智，硬做订阅伤口碑。

### L3 主题人生包（DLC，长尾收入）
- 单包 ¥380–680：县城青年 / 女性重启 / 大龄转行 / 海外漂泊 / 照护者等。每包 = 专属事件 60–100 条 + 专属结局判词 + 影子线。与机构/创作者联名包五五分账（比例待谈判）。

### L4 定制服务（高客单，低量，验证 B/C 之间的桥）
- 专属人生局：玩家提交真实分岔，人工+AI 制作专属可玩局（送自己或送朋友/伴侣作礼物），定价 ¥9,800 起/局，限量接单。礼物属性强、毛利高，且产出的故事（经授权）是最好的宣传素材。

### L5 B 端授权（收入主引擎，数据成立后启动）
- 学校生涯教育版：按校/年授权，暂定价带 ¥50,000–100,000/校·年（含教师手册、讨论课教案、教育版内容审核说明）。
- 企业员工发展/关怀版：按场次或年授权，暂定 ¥80,000–150,000/场次包（含量身主题包与聚合复盘报告）。
- 咨询师工具版：按席位年费（待定价，先访谈 5 位咨询师再定，待验证）。
- 出版/IP（远期选项，不进近期计划）：精选故事墙成书、播客/影视授权——只登记为可能性，不做收入假设。

### 10.6 为什么不靠广告（算账）
网页游戏展示广告 CPM 约 $0.5–2、激励视频约 $4+（行业口径，地区差异大）。按每局 2 次插屏、CPM $3 的乐观假设：10 万局 ≈ $600 ≈ ¥9 万；100 万局才 ≈¥90 万，且广告直接破坏沉浸感与人文口碑。结论：广告只可作为 100 万量级后的补充（如结算页非侵入位），**不进 MVP、不进收入主假设**。

### 10.7 收入情景测算（毛收入，未扣支付费/税/成本；转化率取行业常见 0.5%–5% 区间内的保守段）
| 玩家规模 | C 端珍藏（转化 1%，客单 ¥680） | C 端珍藏（转化 2%，客单 ¥980 三件套为主） | B 端（并行） | 合计读法 |
|---|---|---|---|---|
| 1 万 | ¥68,000 | ¥196,000 | — | 只够验证，不够回本 |
| 10 万 | ¥680,000 | ¥1,960,000 | 试点 5 校 ×¥5 万 = ¥250,000 | 副业级收入成立 |
| 100 万 | ¥6,800,000 | ¥19,600,000 | 30 家 ×¥8 万 = ¥2,400,000 | 才进入「项目级」收入 |

成本侧（MVP）：域名+静态托管近乎为零到每月数千日元；LLM 只用于离线内容生产与 L3 定制，在线对局零 LLM 调用（确定性引擎）——这是成本结构的关键设计，单局边际成本 ≈ 0；主要成本是作者时间与事件库审核。盈亏平衡因此主要看时间投入的定价，不看服务器。

## 11. 技术架构（从简单到复杂）

- **MVP（纯前端单页）**：静态站（可挂个人主页同一套 Astro/GitHub Pages 体系）+ 事件库 JSON + 确定性规则引擎（种子随机，同一种子可复现——Loop C 的技术前提）+ localStorage 存档 + Canvas 生成分享卡。无后端、无注册、无在线 LLM。
- **V2（轻后端）**：匿名埋点（完局/分享/付费漏斗，隐私最小化）、种子码与挑战链接的短链服务、Stripe 支付与珍藏版 PDF/海报服务端生成、故事墙投稿与审核后台。
- **V3（B 端与定制）**：机构场次码与聚合报告、L3 自定义起点的 AI 文案流水线（生成→事实/敏感检查→人工抽检）、多语言（日文）内容库与同一引擎复用。
- **可复用資產**：引擎与卡生成器与题材无关，后续主题包/其他人生题材可复用——这是把它当「项目」而非「一锤子产品」的理由。

数据来源清单（L2 用，逐条查证后入库）：日本——总务省/厚劳省工资与就业统计、国税厅民间给与实态、住宅与育儿费用公开统计；中国——国家统计局分行业工资、各地房价与社保公开数据；跨国对照——世界银行/WHO（仅在做国家对照内容时）。原则：**数字进事件文案前必须有可点击出处，查不到就降级为定性描述。**

## 12. 指标、实验与止损

核心漏斗：访问 → 开局 → 完局 → 生成卡 → 分享/发挑战 → 被分享者开局 → 付费。
北极星指标：**每千名玩家产出的有效分享卡数**（同时反映完局与分享意愿）。

首轮 A/B 实验清单（按优先级）：
1. 结算卡版式（判词大字版 vs 年表版）对分享率的影响；
2. 影子「瞥一眼」放在 30 岁还是结局才揭晓，对完局率与讨论量的影响；
3. 轻局 6 分钟 vs 10 分钟（事件数）对完局率的影响；
4. 珍藏定价 ¥480 vs ¥680；
5. 落地页标题（《如果那年》情绪版 vs 玩法直述版）。

止损/转向线（暂定，内测后与用户确认成正式版）：
- 内测完局率 <40% 且改一版后仍不升 → 玩法不成立，停 C 端，转做 B 端课堂工具小样或直接止损；
- 公开发布 4 周分享率 <8% → 裂变不成立，不追加买量，复盘卡与钩子后再决定；
- 珍藏上线 4 周付费转化 <0.3% → 改卖 B 端与定制，C 端保持免费做影响力资产；
- 总投入上限沿用副业纪律（现金预算 ¥100,000 为此前提出、尚未正式确认的口径——本项目启动前请用户确认是否沿用）。

## 附录 B：事件样例（10 条，示意结构与语气）

1. （27 岁，大厂线）项目上线那晚你睡在公司。奖金到账时，你给家里换了台冰箱。母亲说：冰箱很好，就是你过年能回来吗。
2. （29 岁，通用）父亲体检有个指标异常，要复查。那一周你什么选择题都做不好。
3. （31 岁，回家乡线）你带学生去省里比赛拿了奖。老同学在群里发大城市的新房，你关掉手机，去给母亲热牛奶。
4. （33 岁，创业线）账上只剩四个月工资。你第一次认真想：如果当年去了大厂，现在是不是已经在看房了。（触发影子瞥视）
5. （35 岁，通用）你和伴侣为要不要孩子谈了整整一个秋天。没有对错，只有你们的日子。
6. （38 岁，留学线）你在异国的超市里学会做家乡菜。视频那头，父亲的头发白了一大半。
