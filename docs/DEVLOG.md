- **设计裁定：结算分岔图改纵轴立轴**（详见 VISUAL-DESIGN.md 第四节）。横轴图会让纵向位置被读成好坏（上好下坏），与「结局无尊卑」冲突；改纵轴后纵向只表示时间，分岔往左右展开，走过的线居中成脊、未选支流左右交替分出并淡去，图下接完整人生记录。该图定位为结算回顾展示，不是游玩中的生长动画。

- **浪潮事件组设计**（docs/WAVE-EVENTS.md，1192ef83）：大事件必经不可改，落到玩家头上的剧情线路由早年标记决定；四段弧线（伏笔→本体→余波→影子对照）共 11 组。设计结论：必经不能靠高权重，需要引擎加 wave 字段做前置检查，且分岔/瞥视需配套「到龄顺延」。试点定为 c1978 房价起飞组与 c1955 恢复高考组。
- **世界线视觉样稿 W1–W4**（docs/ui-proposals/，1192ef83）：长卷世界树 / 世界线束 / 纵深扇面 / 分形墨洇，各带交互样稿与说明。采用拼法：结算图用纵轴立轴（由 W1 演化）、瞥视借 W2 邻束亮起、分享卡借 W4 墨洇结算帧、W3 留作分岔口仪式备选。
