# 协同组合与稀有结局系统 v1（2026-10-31）

> 用户点题：学《以撒的结合》的道具协同——大量前置条件互相组合，拼出千奇百怪的化学反应，并因此产生极低概率的特殊结局（世界首富、校长、研出神药……）。两条红线由用户亲定：**不许玄幻**，**避开政治**（不能成为总统之类）。

## 一、机制：人生没有道具，但有「轨迹」

以撒的协同 = 道具 A + 道具 B → 新效果。人生版的翻译：**标记就是道具**。玩家每个选择留下的标记（flags）、走过的事件链、数值形状，组合起来满足某组前置条件时，触发普通池里永远抽不到的东西：

1. **组合事件（synergy events）**：需要 2 个以上来自不同分岔的标记同时成立才进池。例如「有伴侣 + 买了房 + 有孩子」三标记齐备，才会遇到那个普通的周末早晨；「单身 + 自由 ≥70」才有独行者专属事件。组合让每局的「人生质地」不同，而不只是事件不同。
2. **稀有事件（rare events）**：条件满足也只是拿到「抽奖资格」——每年按 chance 掷一次骰（0.4%–30% 不等）。条件是门票，运气是另一道门。这是以撒味的来源：你凑齐了 build，也得等它触发。
3. **轨迹链（trajectories）**：稀有事件命中后写入轨迹标记（traj_*），开启下一环稀有事件。创业线：副业起步（side_start）→ 中年副业（side_job）→创业窗口 →拿到融资 →上市敲钟 → 特殊结局。每环概率相乘，链越长越稀有——传说结局的低概率是结构算出来的，不是写死的。
4. **特殊结局（special endings）**：65 岁评定时，先查特殊结局表（按传说 > 史诗 > 稀有排序，取命中的最高档），命中则它成为这一局的标题与分享卡头条；未命中才走常规形状判词。特殊结局是「称号」，不是「更好的命」——判词与尊严规则不变，平凡结局照样体面。

## 二、概率目标（蒙特卡洛验收，不靠感觉）

| 档位 | 单局命中目标 | 例 |
|---|---|---|
| 传说 legendary | 每条 ≤1%，合计约 1–2% | 世界首富、神药研发者、院士 |
| 史诗 epic | 每条 1–4%，合计约 6–9% | 校长、畅销书作家、千万粉丝、子孙满堂、环游世界、定标准的人、县城企业家 |
| 稀有 rare | 每条 1–3% | 天选之人（彩票）、年龄组冠军 |
| 任一特殊结局 | 约 10–15% | 其余 85%+ 是普通而体面的人生——这是产品的底色，不许稀释 |

## 三、红线（写内容时逐条对照）

**不涉政（用户亲定）**：
- 禁止：任何政府职务晋升线与具体官职（总统、部长、省长、市长、局长……）、党派、选举、军队、成为政策制定者。
- 体制内路线只写「单位里的普通人」：岗位、工作、处事，不写职级攀登。
- 白名单（民间/学术/市场荣誉，可以写）：校长（一校之长，教育岗）、院士（学术荣誉）、行业标准起草人（行业协会）、企业家与富豪榜、作家、网红、运动员（业余年龄组）、发明人。

**不玄幻（用户亲定）**：
- 禁止：超能力、预知、穿越/重生实锤、延寿丹式神药、鬼神、风水改命。
- 「神药」只指真实世界的新药研发获批（立项→临床→获批），写的是二十年熬出来的成果，不是灵丹。
- 彩票头奖是真实存在的极低概率事件，可以写，但概率必须如实极低（每局期望远小于 1 次），且文本写「税后、领奖、归于平静」，不写一夜暴富主线。

**其余沿用既有纪律**：文案规则（具体场景、无金句收尾）、敏感题材纪律、结局尊严（稀有 ≠ 高贵，普通 ≠ 失败；特殊结局文案不许贬低没触发它的活法）。

## 四、已落地（v1）

- 引擎：统一条件求值（route/routeIn/require/forbid/all/any/when/stats/chain）；稀有事件年度掷骰；特殊结局评定并上分享卡；轨迹标记 traj_*。
- 内容（src/synergy.js）：稀有事件 16 条（6 条轨迹链的各环 + 独立稀有点）、组合事件 8 条、特殊结局 12 个。
- **实测概率（蒙特卡洛 4000 局随机游玩，2026-10-31）**：任一特殊结局 **10.0%**；传说档——世界首富 0.20%、神药研发者 0.75%、院士 0.47%；史诗档——子孙满堂 4.28%、畅销书作家 1.60%、一校之长 0.97%、千万粉丝 0.47%、定标准的人 0.43%、环游世界 0.13%、县城企业家 0.03%；稀有档——天选之人 0.35%、年龄组冠军 0.27%。12 个结局全部可达。注：随机游玩口径，真人玩家刻意凑 build 时命中率会更高——这正是设计意图（build 可追求，概率不保底）。
