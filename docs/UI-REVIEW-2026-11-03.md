# 主页 UI/UX 评审（用户 2026-11-03 转交，PM 与交互设计视角）

针对 v0.20.1 主页。要点存档，施工逐条销账：

## 一、信息架构
- 流线倒置：顶部先放 5 张路径卡与主按钮，关键配置（年代、自动推进、速度、种子）堆在中下部——配置滞后于执行。应重构为：标题 → 配置区（年代/速度/种子） → 底部或固定位主按钮。
- 区块缺分界与视觉锚点：通栏单列，留白无 8px 网格规范；路径卡与功能控制区视觉权重平铺，无 Section 分隔。

## 二、视觉与微交互
- 选中态区分度低：选中（深色粗边/底）与未选中（近背景色）对比不足，移动端低亮度下看不清当前选了什么。统一 Segmented Control 规范、增强选中高亮。
- 速度控件语义模糊：「慢·细读/中·通读/快·扫读」拥挤、字号小，与「自动推进」开关形态同质化，看不出是单选组。
- 排版：卡片描述行距不足、密度高；字体阶梯未建立（主标题/卡片题/描述/标签/页脚梯度平缓）。

## 三、可用性
- 种子码与每日一局定位割裂：输入框、「用这个种子」、「今日一局」堆叠，逻辑不直观；「明日一局」预告文本长得像按钮，易误点。
- 存档恢复优先级反了：有未完成存档时，「继续上次的人生」应是最高优先级的主行动点，现为弱化的次级样式。

## 四、其他
- 5 张路径卡与「从童年开始」功能重叠：须明确卡片是预览还是入口，避免重复引导。
- 页脚的反馈入口与版本号过于隐蔽：调试信息与核心配置解耦，独立收纳。
