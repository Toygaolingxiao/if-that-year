# 视觉与出图设计 v0.1

> 用户 2026-10-30 问：网页风格设计呢？整个出图设计呢？
> 一句话：**像一封写在纸上的人生。** 不做游戏味，不做 AI 味——用户在个人主页改版时已明确否掉过深色+渐变+发光的「AI 味儿」方案，本项目沿用同一套被他认可的纸感系统。

## 一、网页风格系统

### 1. 设计语言
- 关键词：纸、信、手账、路。页面是「一封正在写的人生信」，事件卡是信纸，结算卡是一张可以寄出去的明信片。
- 禁忌（硬性）：渐变、发光、玻璃拟态、深色霓虹、游戏式金币/宝箱图标、排行榜红金配色。出现任何一项就算跑偏。

### 2. 色板（与作者主页 v0.2 同一套，形成个人产品矩阵的统一识别）
| 角色 | 值 | 用法 |
|---|---|---|
| 纸色 | `#FAF8F4` | 全站底色 |
| 墨色 | `#23211C` | 正文 |
| 松绿 | `#2F4A3C` | 唯一强调色：品牌、按钮、实线人生路 |
| 线色 | `#DDD6C9` | 分隔线、卡片边框、六维条底 |
| 影子灰绿 | `#8A948C` | 只给影子人生用：它的文字、虚线、卡片边框都用这个色——一眼分清「这不是你走的那条」 |
| 卡面 | `#FFFDF8` | 事件卡/结算卡底 |

### 3. 字体
- 标题/判词：衬线（Songti SC / Noto Serif SC / Georgia 兜底），字距略开。人生感来自衬线，不来自装饰。
- 正文/选项：无衬线系统字体，15–16px，行高 1.75（已在原型落地）。
- 数字（年龄/种子码）：等宽或 tabular，保证年表对齐。

### 4. 签名视觉：一张越长越复杂的「分岔路图」
全产品唯一的图形主角，不用插画、不用 AI 生成图：
- 现行画法（卡面）：一条松绿实线从左到右贯穿一生（横轴是年龄），每个大分岔处，实线继续向前，同时分出一条影子灰绿**虚线**支路，虚线在瞥视年龄点后渐渐变淡、断开——像一条没走完的路。结算页的画法已另行裁定为纵轴（见第四节）。
- 这张图由玩家本局的真实选择数据画出来，每局都不一样。三个出现位置的现状：游玩页顶部是简化版横向进度路图（随年龄推进，已落地）；结算页按第四节裁定改纵轴立轴（待落地）；分享卡判词卡正中绘有分岔路图（Canvas 版，已落地，迁纵轴随结算图一并做）。
- 为什么不用 AI 插画：①每局生成成本与等待不可控；②AI 图自带「AI 味」，与文字原则（自然人语感）冲突；③数据画出来的图才是玩家自己的，插画是谁的都一样。AI 生图只允许用在落地页/OG 图这类离线物料上（1–2 张，人选定后固定，不进对局）。

### 5. 关键组件规范
- **事件卡**：信纸式白卡，左上角小字年龄，正文 3 行内，选项是整块可点的「路牌」按钮（浅边框，hover 才变松绿）。
- **六维条**：细线条 + 数字，不做血条式填充动画，不变红警告——数值是日子，不是 KPI。
- **影子瞥视卡**：影子灰绿虚线边框，文字略透明，像隔着雾看；「不看」按钮永远和「看」一样大，不诱导。
- **里程碑留言**：输入框做成信纸横线样式，一行，不弹键盘遮挡主要按钮。
- **动效**：只做一种——新一年的卡片轻轻浮现（淡入+上移 4px，≤200ms）。不做翻牌、不做粒子、不做音效（默认静音是人文产品的体面）。

### 6. 适配
手机竖屏优先（360–430px 单列，拇指区在下半屏）；桌面端居中 640px 列，不拉宽。深色模式暂不做（纸感只在浅色成立），跟随系统也不切换。

## 二、出图设计（分享卡 / 结算卡）

出图是裂变的主引擎（设计书 §8.1），按「海报」标准做，不按「测试结果图」做。

### 1. 规格
- 尺寸：两卡型 × 两比例——判词卡与流水账卡，各有 4:5（1080 × 1350）与 9:16（1080 × 1920），PNG（已落地）。
- 生成方式：浏览器内 Canvas 2D 直出，零服务器、零等待、零成本；字体用系统衬线兜底（Songti/Georgia），不嵌网络字体，保证离线可出图且不翻车。

### 2. 版式（判词卡，从上到下五区）
1. **眉题**：小字「如果那年 · 另一条路」+ 种子码（右上角，小而清楚——这是回流入口）。
2. **判词**：衬线大字两行内，全卡最大字号，是截图传播的标题。
3. **分岔路图**：本局分岔路图绘到卡面正中（实线一生 + 虚线影子），图下小字标注关键分岔一个（「28 岁 · 你没回老家」）。
4. **两行对照**：左列「这条路：大城市大厂，65 岁退休」；右列影子灰绿字「另一条：回了家乡，两个孩子，周末钓鱼」。
5. **落款**：六维小条图（不带名次、不带分数排名）+ 网址 `if-that-year.pages.dev` + 一句钩子「你敢看你的另一条路吗？」。

### 3. 卡型现状（原 A/B/C 三模板的落地形态）
- **判词卡**（原 A 判词版）：已落地，默认卡型。判词最大、路图次之，版式见上。
- **流水账卡**（由原 C 年表版演化）：已落地。公元年轴 + 关键节点 3–5 个（第一次分岔选择、稀有事件、后段分岔、特殊结局）+ 判词节选 + 六维小条；9:16 版另补一段年表节选。适合愿意读字的人。
- B 路图版：未实现为独立卡型——路图现是判词卡正中的元素；是否再拆独立卡型，等分享数据再定。
两卡型共用同一套数据与色板；卡型 × 比例共四种组合，在结算页分享台内切换并实时预览。

### 4. 出图红线
- 不出现「击败 X% 玩家」「人生评分 82 分」类排名与总分——与结局尊严矩阵冲突。
- 不把玩家的里程碑留言整段印上（那是私人的）；留言只印玩家在结算页主动勾选「放进卡里」的那一句。
- 卡面不放二维码贴纸式大图（扫码率低且丑），网址用短域名文字即可；以后有专属域名再换。

## 四、结算回顾图裁定（2026-10-31）

分岔路图在结算页的定位与画法，用户逐条裁定，落地时按此验收：

1. **定位**：它是人生回顾的展示，不是游玩中的生长动画。游玩页头部保留简洁小路图；结算时整图一次展开。
2. **只强调分岔点**：每个分岔口标出走过的路与未选的路，以及那一年选了什么（小字贴分岔点旁），不需要满卷繁线。
3. **纵轴立轴**：纵向为时间轴，自上而下从 22 岁到结束年龄；不采用横轴。理由：横轴图的纵向偏移会被天然读成价值（上好下坏），纵轴下纵向只表示时间早晚，误读从根上不存在。
4. **中脊原则**（中轴原则的纵轴版）：走过的线居中成脊；未选支流在分岔口往左或往右分出（左右交替），长一段即变细淡去；横向偏移永不编码好坏，支流上下/左右顺序按游戏内选项呈现顺序，不按数值效果排。
5. **图下接人生记录**：图下方紧接完整流水账（带公历年份），整页是一幅自上而下的卷：先一张图看全部分岔，再一卷记录看完一生。
6. 分享卡路图版与此同源同形（卡面本为竖版），截取/转绘时同样遵守第 3、4 条；W4 墨洇帧用于卡面时，绿线走中间带、墨雾向左右洇开。
