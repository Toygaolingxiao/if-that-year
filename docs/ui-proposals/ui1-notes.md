# 方向一：克制精致化 — 排版决策

## 字号阶梯（只用七级，衬线只给「要被记住的话」）
- 30 衬线：开局大标题；25 衬线：判词（全站第二大，只出现在结算）；21 衬线：结算小标题；17.5 衬线：路线名；16 无衬线/行高 1.9：正文；13.5：流水账与次级信息；12/11：元信息与栏目标签（字距 .22–.3em）。
- 五维数值用 20px 衬线（像报纸数据栏），年份与种子用等宽——数字各归其位，不混排。

## 间距系统（8 的倍数，不用随手数）
- 节奏单位 8：组内 8/16、区块间 24/32、卡内边距 32（移动端 24/19）。
- 正文行高从现版 1.75 提到 1.9：出版物感主要来自行间，不来自装饰。

## 线宽用法（线有语义，不只做分隔）
- 1px 线色 #DDD6C9：结构线（卡边、数据条上下沿）；更浅的 #EFEAE0 只做组内发丝线。
- 2px 墨线全页最多两处：路线表上方、分享台上方——压住「主要动作」，其余地方不许用。
- 虚线专属于影子/没走的路（路图支线、对照栏分隔、流水账与正文的分界）；实线是「走过的」，虚线是「没走的」。
- 去掉现版点阵底纹与重阴影：纸是平的，卡片只留一层极软的影，精致靠对齐与留白。

## 流水账的呈现
- 账本式两列：左列等宽年份（公元年 · 年龄）右对齐，右列正文；行间只有发丝线，没有底色块、没有圆角行。
- 最新一行不用高亮底色，只用松绿年份 + 左侧 2px 松绿竖条标出——和选项 hover 的左条是同一语言。
- 标题行右侧带「已走过 N 年」，让「流」有进度感；容器内滚动，新行追加在底部并自动滚到最新。

## 设置区收纳逻辑
- 三个设置（年代/跨度/种子）收进一个块：顶部一条实线与引言分开，内部每组一行——固定宽标签列 + 内容列，组间发丝线，不用卡片阵列、不用表单式堆叠。
- 年代从现版四张按钮卡改为四行文字行（名 + 一行描述，选中只靠左 2px 松绿条与名字变色），信息密度降一半。
- 跨度是一行分段文字（选中加下划线），种子是一行下划线输入 + 两个文字按钮；块尾固定一行「这一局：…」摘要回显，改任何一项只动这一行。
- 路线表压到页面最后并编号 01–05 做成目录页：设置是准备，选路是动作，动作放最后、给最重的线（2px 墨线）。

## 分享台
- 结构按「寄信」排：添一句话（信纸式下划线输入）→ 卡型 → 尺寸 → 左预览右动作；预览按出图五区（眉题/留言/判词/路图/落款）原样缩小，与真实卡同构，所见即所得。
- 按钮只许一个主按钮（生成图片），其余全部降为幽灵胶囊或文字按钮；发帖文案先给预览再让复制，不让用户盲发。
