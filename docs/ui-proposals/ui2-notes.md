# UI 方向二（大胆）· 设计说明

**签名概念（一句话）**：一册装订起来的人生档案——分岔路放大为贯穿全页的长卷脊柱，年份是邮戳，流水账是装订线钉住的账页，传说结局盖一枚朱印；玩家记住的不是一套配色，而是「我的这一生，被装订成了一册」。

## 与方向一（保守精致）的取舍
- 方向一在现版式里提质感：更稳、改动小、上线快，但签名仍停留在「卡片顶部一条小路图」，远看与普通文字游戏难区分。
- 方向二把路图升为版面结构本身（开局起笔、游玩长卷、卡面正中同一张图），并引入档案物质感（邮戳/装订线/登记表/朱印）换取不可替代的识别度。
- 代价：放弃方向一的轻盈——信息密度更高，首屏更「满」，必须靠层级纪律守住克制（正文仍只许一件事居中）。
- 共同底线不变：暖纸+松绿+宋体、无深蓝/渐变/发光、无排名分数、不堆砌功能入口。

## 关键手法
- 路图三态：开局只起笔（第一道岔口虚线若隐若现）→ 游玩随年龄生长、岔口挂年份 → 结算完整长卷直接成为分享卡正中。
- 朱红（#A6493B）是唯一新增色，只许出现在邮戳、当前点与印章上，全册不超过三处。
- 开局表单改「档案登记表」（出生年代/走到几岁/种子码三栏登记），选项改带编号的「路 〇一」路牌。

## 风险点
- 邮戳/印章/竖排字等母题用过量会滑向「文创周边感」，需限制出现频次（样稿已按每屏 ≤2 处邮戳控制）。
- 路图在 80 岁长局+五岔口时横轴拥挤，需做岔口标签的错层避让，移动端 360px 宽要实测。
- 朱红印章只给传说/史诗结局时，玩家可能为「盖印」刷局，与「结局无尊卑」的设计原则有张力——印章文案须只记事、不评级。
- 装订线+打孔的账页在深色截图/低清屏上易显脏，上线前需真机截图验收。
