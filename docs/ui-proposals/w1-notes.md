# W1 · 长卷世界树（说明）
- 概念一句话：整局是一幅横轴手卷——卷面向右慢慢推开，卷上只长一棵分岔树，你走的那支是松绿粗线，没选的支流灰绿虚线往前长一段就淡掉。
- 样稿：w1-scroll-tree.html（Canvas，单文件；控制条：过一年 / 分岔口三选一（真实选项）/ 取这一条 / 重置；演示路线为「去大城市，进大厂」）。

## 动效节奏参数
- 展开：每过一年一「段」，950ms/段，段间停顿 90ms；缓动用 easeOutCubic 叠加 5 次微顿挫（振幅 0.8%）模拟纸面摩擦，禁止匀速平移。
- 分岔：选完自动再长一年（同上节奏），让「裂开」当场可见；支流出生不另做动画，随主干生长同步伸出。
- 结算收卷：1700ms easeInOut，相机与缩放同步回到全卷（缩放 ≈ 960/2260 ≈ 0.42），影子支流整体再褪色 50%，分岔选择小字在后 60% 进度淡入。
- 当前点呼吸点 2.9s 周期、振幅 ±1.1px，是全稿唯一循环动效；遵循 VISUAL-DESIGN「只做一种动效」的克制口径需评审豁免此点与展开动画。

## 适合的位置
- 游玩页顶部路图：主用位——现有 roadSvg 的直接升级（随年龄展开 + 支流生长），窄版只取展开与主干，支流淡化可保留。
- 结算页：主用位——「取这一条」即结算仪式本身，收卷全貌比静态图更有「取其一」的分量。
- 分享卡 B 路图版：静态截取收卷全貌即可出图（Canvas 同源绘制，零额外成本）；A 判词版不建议用，判词优先。
- 开局页：可用 22 岁起笔的半展开卷做眉题背景一小幅；瞥视：不建议——瞥视要的是雾感单条虚线，长卷全貌会泄底。

## 实现成本与性能
- 节点上限：一局主干 87 点（0.5 年步长）+ 支流 16 条 × ≤29 点 ≈ 550 点，逐段描线 Canvas 毫无压力；移动端同量级可跑满 60fps，无需离屏缓存。
- 绘制要点：逐小段变线宽/透明度模拟笔触收尾；虚线支流用 setLineDash，缩放后需按 1/scale 修正 dash 长度，否则结算全貌下虚线会糊成实线。
- 数据现成：分岔年龄、选择、种子 RNG 均已在引擎里，接入只需把 S.log/forksDone 映射成支流生成参数；展开进度可由 drawAge 单值驱动，与存档兼容。

## 风险
- 横轴长卷与手机竖屏冲突：游玩页只能放窄幅窗口（跟随展开前沿的相机），玩家中途想回望全程需另给「收卷看全貌」入口，否则会迷路。
- 展开动画每步近 1 秒，一局 43 年累计等待偏长——正式版建议只在分岔年与瞥视年走完整段动画，平年缩到 300ms。
- 支流漂移全靠程序摆动生成，个别局可能出现支流互相交叉或贴边，需给漂移加同向不交叉约束（按出生顺序分配纵向带宽）。
