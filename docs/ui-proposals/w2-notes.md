# W2 · 世界线束 —— 设计说明

**概念一句话**：几十条线缠成一束往前流，每个分岔口整束裂股膨胀，你只取其中一条；全程摊在一幅从左向右慢慢推开的画轴上。

**形态要点**
- 线束：46 条极细线同点出发，靠正弦编织互相穿插成「束」，不是平行线阵；分岔口按真实年份（25/28/31/33/38/44/52/58）整束裂成上下两股，分流距离逐口收窄，束越老越宽但不散架。
- 取其一：玩家线是全图唯一松绿（#2F4A3C），其余墨灰深浅不一；每条影子线相对玩家定义——在某个分岔口与你分道、此前与你完全重合，所以「另一条路」是贴身分出去的，不是远处别人的命。
- 瞥视：影子那股用影子灰绿（#8A948C）短暂亮起 2.4 秒并标注「另一条路」，与 VISUAL-DESIGN 的影子色规范一致，不新增颜色。
- 画轴：纸面随年龄向右生长，右端轴杆跟着前移，上下裱边双线；没推开的部分不存在——未来不是被遮住，是还没展开。

**适合的位置**
- 开局页：可做主视觉（静止在 22 岁一束未分，最克制），或只用一小段。
- 游玩头部：最适合——路图随年龄生长本就是既定签名视觉，线束版信息量更大；建议只显示玩家线所在的那股邻域（见降级）。
- 瞥视时刻：本方向的杀手锏，邻束亮起比虚线支路更有「它一直在旁边」的感觉。
- 结算页：全束展开 + 他线淡至 26%，是「取其一」最完整的一帧。
- 分享卡：截取结算全貌帧即可出图，判词压在束流上方；但线数要减到 20 条以内，小图才不糊。

**性能账**
- 46 条线 × 每 0.3 岁采样 ≈ 每帧 6,600 段折线 + 玩家线 172 段，Canvas 2D 桌面与中端手机均可满帧；编织相位只用两个正弦，无逐帧分配。
- 帧率策略：静止时把编织时间冻结（只保留推开动画），滚动/切后台自动停 RAF。

**移动端降级**
- 线数 46 → 24（每股邻束 5 → 3），采样步长 0.3 → 0.5 岁，DPR 上限 1.5。
- 只画玩家所在股 ± 一层邻股，其余股以两条边界线暗示；瞥视时才补画邻束全股。
- prefers-reduced-motion：取消编织漂移与推开动画，年龄跳变直达。

**风险**
- 「世界线」一词自带动漫联想：产品文案里不出现该词、不做编号与仪表，只叫「线束 / 另一条路」，靠形态不靠符号。
- 线太多太乱是主要观感风险：分流距离与线数必须联动克制，宁可少线，不要毛线团。
- 结算时他线变淡可能被读成「别人的人生更差」：文案须明说淡下去只是这一局不归你看，与项目「结局无尊卑」一致。
