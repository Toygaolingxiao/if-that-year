# W3 · 纵深扇面

**概念一句话**：所有可能的路从远处一个消失点向你扇形展开，每过一个岔口扇面翻一倍；最后你从扇面里抽出一条，落到自己脚下。

**适合位置**
- 开局第一屏：画轴从中央向两边推开是全产品最强的「开场仪式」，只此一次，不复用。
- 分岔口（主战场）：每次大分岔触发扇面翻倍，膨胀感即选择的分量感。
- 影子瞥视：邻近的一条线短暂变亮（灰绿虚线），看完即退远——扇面天然支持。
- 结算/分享卡：选定后镜头推近、那条路落到近处定格，可直接作 B 路图版卡面的变体。

**与横向长卷（W2 档案长卷）的取舍**
- 长卷是横轴时间：强在叙事、可回望、承载年表与流水账；扇面是纵深：强在一瞬间「全部可能性都在眼前」的压迫感与仪式感，但不承载信息。
- 分工建议：扇面管「选」（开局与分岔口），长卷管「记」（游玩页顶与结算年表），两者不抢同一屏。

**移动端窄屏可行性**
- 纵深是纵向的，天然贴合竖屏：消失点在上、扇面向下张开，360–430px 宽即可成立，不需要横向空间。
- 窄屏靠「层数」造膨胀而非横向密度：每层带宽压到屏宽，线变细、变淡即可；末端圆点热区放大到可点（样稿 5px 视觉点 + 按层只激活当前层圆点），或改「点左半/右半屏选支」。

**风险**
- 游戏分岔是 3 选，扇面是 2 分：落地要么做三叉混编节点，要么把第三选项作「留白支」——需先定口径，别硬塞。
- 线数指数增长：SVG 6 层 127 条线流畅，再深必须换 Canvas 或只画剪影，否则低端机卡顿。
- 透视过强会滑向科幻/游戏味：须压住——无渐变、无发光、线宽克制，扇面只在开场与分岔瞬间动，平时静止如纸。
