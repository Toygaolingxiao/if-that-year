# W4 · 分形星尘（墨洇）说明

概念一句话：世界线在每个分岔口分形裂开、密成洇在宣纸上的墨雾，你取的那一条始终是清晰的松绿——无限不是画出来的，是裂出来的。

## 形态
- 主干：8 个分岔口（25/28/31/33/38/44/52/58，取自 events.js），每口全线裂半，1→2→…→256 条；张角逐级收窄，终点收进同一画幅，像河口三角洲。
- 雾层：主干小枝（深度 2）+ 65 岁处 256 朵终点冠（深度 3），低透明墨色，密度即「无限」；雾的浓度以约 22 秒周期缓缓涨落（呼吸式生长）。
- 画轴：横轴展开到哪、分形的前沿推进到哪；取定一个分岔后，未选线透明度再退一层，字面意义上洇进纸里当底纹。

## 分形深度与性能的账（实测，种子 20261031）
- 线段总数 3,686：主干 766 + 小枝 1,128 + 冠雾 1,792，深度上限 主干 8 代 / 小枝 2 / 冠 3。
- 每帧描边：雾层按深度合并为 6 次批量 stroke；主干 766 段逐段（需按前沿渐入）；主角线 1 条折线描 2 遍。全帧约 775 次 stroke，桌面与主流手机 60fps 无压力。
- 生成是一次性的（种子随机，约 3.7k 段的对象数组），帧内只做坐标与透明度计算；低端机兜底方案：雾层烘焙到离屏 canvas，仅在前沿跨过分岔口时重烘焙，主画布只剩主干+绿线。

## 适合位置
- 结算页主视觉与分享卡（全貌帧自带传播力）；游玩页顶部可放压缩版（只到当前年龄的前沿）；开局页慎用全幅，会抢选路动作。

## 卡面构图（样稿「看卡面效果」，4:5）
- 五区沿用 VISUAL-DESIGN §二：眉题+种子 / 判词四行（events.js 原句）/ 分形带（占卡面约 27% 高，绿线穿行，下注「28 岁 · 你没回老家」）/ 两行对照 / 五维小条+钩子+网址。
- 卡面里八个分岔按已取定处理：未选线退到底纹层，绿线是唯一实色——截图缩到信息流尺寸，仍先读到绿线，再读到雾。

## 风险
- 滑向星空/宇宙的防线：坚持浅纸底、墨色低透明、无发光、无闪烁粒子、无深色背景；雾的质感来自毛细小枝与洇退，而不是点状星尘——一旦改成深底白点，立刻出戏。
- 绿线压雾靠一层卡面纸色宽笔垫底，PNG 压缩下可能略发灰，出图前需在小红书/微信压缩链路实测一遍。
- 呼吸动效与现行规范「只做一种动效（卡片浮现）」冲突，采用需单独豁免且幅度保持在几乎察觉不到的量级；另，本样稿分形由固定种子生成，正式版必须改由玩家本局真实分岔数据驱动，否则每局同图，签名就没了意义。
